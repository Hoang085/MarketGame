# Keepsake Lane (tên tạm)
Game merge-2 kiểu Travel Town, theme **tiệm đồ cổ + bí ẩn gia đình**, nhắm thị trường global (US, GB, Tier-1). Chốt tạm ngày 2026-10-26.

Giai đoạn hiện tại: chuẩn bị concept 2D và playable ad để test thị trường. Chỉ làm game khi chỉ số quảng cáo tốt.
